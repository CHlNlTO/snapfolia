# Changelog v2.1.0

## New Features and Updates

- **Celery** (v2.1.0): A distributed task queue to handle asynchronous job processing.
- **Redis**: A message broker for Celery to store and manage task states.
- **Docker**: For containerizing the application, ensuring ease of setup and deployment in different environments.
- **Local-Only Setup**: This setup is strictly for local development purposes and does not include cloud or production-specific configurations.
