# v1.2 Updates


## New Features amd Improvements:

- **Dockerized Backend**: The backend has been containerized using Docker, ensuring easier deployment and scalability across different environments.

- **Object-Oriented Programming (OOP) Code Structure**: The codebase has been refactored to follow OOP principles, improving maintainability, modularity, and readability.

- **Docker Build Tagged as v1.2**: A Docker image for the backend has been built and tagged flask-backend:v1.2, streamlining version management and deployment.

- **Queueing Removed**: The queueing system has been removed.
