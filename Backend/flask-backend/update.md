# v1.2 Updates


## New Features amd Improvements:

- **Object-Oriented Programming (OOP) Code Structure**: The codebase has been refactored to follow OOP principles, improving maintainability, modularity, and readability.

- **Queueing Removed**: The queueing system has been removed.

- **Grounding Dino Loaded Locally**: The Grounding Dino model has been loaded locally, likely for faster inference or for more control over the environment.

- **Backend Uses Certificates**: The backend now requires certificates for secure communication, ensuring encrypted connections between the backend and frontend.
